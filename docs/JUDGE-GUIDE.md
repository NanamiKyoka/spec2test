# 评委向指引规范（强制）

目标：**没看过这个项目的人，打开 3 分钟能明白"这是什么、怎么用、结果凭什么可信"。**

## 1. 首屏三步引导（`#/data` 与 `#/chat` 各一次）
一个可关闭卡片（关闭状态记 `localStorage`，不得每次弹）：
1. **这是什么**：把 3GPP 规范条款编译成可执行测试意图，并用确定性校验器判对错。
2. **怎么看结果**：每条结果先看结论（通过/拒收/弃权），再看六阶段，最后看校验违规。
3. **点哪里开始**：`开始对话 →`（跳 `#/chat`）/ `先看评测数据 →`（留在 `#/data`）。

## 2. 术语就地解释（悬浮或点 `?`，不得要求跳页）
| 术语 | 一句话解释 |
|---|---|
| L1 | 结构合法率：输出能否解析成 IR 且每步有主体/方向/消息 |
| L3 | 关键 IE 命中率：生成字段对官方叶子字段的召回（分母 7 例） |
| gold 字段 | 官方答案里真正赋值的叶子字段总数（42） |
| verdict | `pass` 无违规 / `reject` 有违规且**未写入结果** |
| 弃权 | 输入信息不足时**不发起模型调用**，不是失败也不是 0 分 |
| 符号表 | 从 TS 38.331/36.331 抽的消息与字段路径，用于判"这个 IE 存不存在" |

## 3. 指标必须可追溯到口径
每个指标卡右上角 `?`，点开显示：**计算式 + 分母 + 当前样本数 + 已知限制**。
例：「官方答案误报 0 / 8 —— 用校验器跑官方答案，被误判的条目数；0 表示校验器不冤枉正确答案」。

## 4. 结果区固定结构（对话与单例页一致）
1. **结论行**（一行，最显眼）：`通过 / 已拒收 / 已弃权` + L1 + L3 + verdict 徽标
2. **一句话说明**：为什么是这个结论（如"输入中没有消息名，未发起模型调用"）
3. **六阶段时间线**（默认折叠，可展开）
4. **校验违规**（有则列出 rule/path/detail）
5. **原始数据**（折叠，JSON 只读）

## 5. 空态必须是"下一步"
禁止出现"暂无数据"四个字了事。每条空态给一句**可执行动作**：
- 无会话 → 「点右上角『新建对话』，或直接点下面的示例问题」
- 无运行历史 → 「运行一次用例后，这里会出现记录」+ 按钮「去对话」
- 数据缺失 → 「先运行 `scripts/repro.sh` 生成数据」

## 6. 评审 5 分钟路径（`#/about` 或数据页底部固定入口）
一屏讲清：**问题 → 方案 → 效果 → 局限**，每条不超过两行，并给三个跳转：`看数据` / `试对话` / `看口径`。
必须包含的三句诚实声明：
- 6G 尚未标准化（首个 6G 规范冻结 2028-12），本系统在 NR Rel-19 上验证；
- 暂无专利/软著，真实性由可复现性担保；
- L2（消息序列）不计分，因全库仅 16 个交换，样本量不支持。

## 7. 视觉纪律
- 一屏只允许一个主按钮（`.btn--primary`）。
- 结论用色：通过=绿点、拒收=红点、弃权=灰点；**弃权不得用红色**。
- 数字统一等宽字体；数字列右对齐。
- 不使用骨架屏之外的任何加载动画；生成中显示「已等待 N 秒 · 当前阶段」。

## 8. 验收（每个页面都要过）
1. 首次打开能一眼看到"这是什么 + 点哪里"；
2. 任意术语都有就地解释；
3. 任意指标都能点开看到口径；
4. 任意空态都给出下一步动作；
5. 页面上**不出现**裸的 `undefined`、`NaN`、`[object Object]`。
