# 不在仓库中分发规范原文，只分发抽取脚本与用例编号

benchmark 由 TS 38.523-1 正文切出，含大量规范原文。仓库**只提交**抽取脚本、用例编号清单与 schema 文档；规范正文与切分结果留在本地（`.gitignore` 排除 `data/`、`_scratch/`）。复现者按 README 从 ETSI 下载 PDF 后自行生成。

**Why:** ETSI 版权声明只允许"为实施该规范所必需的摘录"再分发，整段测试用例正文不属于此列；另一个好处是把"可复现"从"我给你数据"升级为"我给你可重放的流水线"，这恰好是本作品宣称的核心能力。
**How to apply:** 任何对外材料（仓库、佐证包、PPT 截图）不得内嵌大段规范原文；引用条款编号与标题可以，正文只做短引并标注出处。
