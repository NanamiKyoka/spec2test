# 指标以 L3（信令 IE）为主，L2（消息序列）为辅

实测本切片 8 个 NTN 用例共 116 个步骤，但只有 **33 个「方向+消息」交换**；其中 3 个用例仅 1 个交换、1 个用例 0 个（6.7.1.5 是纯计时/测量步骤）。因此把 L3「具体信令内容」定为主指标，L2 降为辅助指标，L1 仅作合法性门槛。

**Why:** 每组只有 1–2 个交换时，L2 几乎不可能有区分度（对或错的概率被样本量吞掉）；而 L3 的 IE 表在 7 个用例里都很厚，能给出真正有区分度的 recall。
**How to apply:** 方案中先报 L3 逐例 recall；**L2 不计分**，只以"系统输出 vs 官方序列"的并排对照做定性展示（2026-10-29 决定）。分母披露：L2 只在 7 个用例上有交换（6.7.1.5 为 0），L3 只在 7 个用例上计（6.7.1.1 原文为 None）。

## 补充（2026-10-29 实测后）
全库仅 16 个方向-消息交换（单例 0–4 个），**不具备统计区分度**：对错各一即可让分数翻倍。故 L2 彻底退出计分，只保留定性对照。这是样本量决定的，不是实现问题。
