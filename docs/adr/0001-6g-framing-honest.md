# 6G 定位：明说未标准化，NR 规范作为验证语料

赛题面向 6G，但 6G 至今没有可执行的一致性测试规范（3GPP Rel-20 研究期，Rel-21 才出规范），因此不存在"6G 一致性测试"这一产品。我们决定在方案第一页明说：本系统是面向 3GPP 系测试规范的方法，在 NR Rel-17/18/19 上做可复现验证，并给出迁移路径；不把 5G 包装成 6G。

**Why:** 评委是这行的专家，看语料文件名就能认出 38.523；隐瞒只会把"技术没底"升级为"诚信问题"，而本项目唯一的护城河正是诚信（见 ADR-0002）。
**How to apply:** 任何对外材料（方案书、演示、答辩）不得暗示已存在 6G 用例；6G 关联只通过"方法同构 + 跨域迁移实验"来论证，且必须给出实测衰减数字。

## Considered Options

- 不说明来源，笼统称"6G 智能体"——短期好看，被追问即崩，且与诚信定位冲突。
- 改做 6G 需求/技术追踪类产品（P1）——真 6G，但失去"官方答案即标准答案"的客观自证，16 天内难以建立可信金标准。
