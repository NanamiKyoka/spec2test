# 评测诚信：遮住官方答案生成，不用参考答案改写

基准测试集由公开规范自动切出「输入 / 官方答案」对。评测时**遮住**官方答案（测试步骤序列、具体信令内容），只向系统提供测试目的与条款，由其生成后再与官方答案比对。禁止把官方答案作为上下文喂给模型后"改写"。

**Why:** 参考答案可见的生成能轻易刷到高分，但评委一眼看穿是作弊；而低分 + 逐例失败剖析 + 开源评测脚本，是单人团队能建立的最强可信度。
**How to apply:** 评测脚本必须开源并可由第三方复跑；任何分数默认标注"遮答案"；失败案例逐条公示，不得只报平均分。

## Consequences

- 指标会明显低于"参考答案可见"的做法，方案中需主动解释量级原因。
- 评测集自动构建流程必须严格：输入侧字段与答案侧字段要有物理隔离，避免泄漏。
