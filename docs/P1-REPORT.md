## 二、修了什么
1. 归属改为**按表格标题里的用例号**（不再按页区间猜），并归一化 `6.1.7.x → 6.7.1.x`。
2. 跨页续表：无标题时沿用**本页上方标题 → 上一页最后标题（carry）**，并只承接最近一次成功归属的用例。
3. IE 只保留**叶子字段**（有取值、非 `::=`、非 `{` 容器），去重。
4. 评分 F1 改为 **LCS 顺序对齐**，避免乱序命中被算对。
5. 裸 prompt 的 dry-run 桩改成中性文本（原桩硬编码 `SIB19`/`RRCSetupRequest`，会造出虚假高分）。
