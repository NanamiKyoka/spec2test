# 作品简介

**问题.** 3GPP 一致性测试用例是终端入网的关卡，却长期靠人工从规范里抄条款、拼步骤、填 ASN.1 字段。单份 TS 38.523-1 有 6994 页、1181 个用例，每个 release 更新都要重写，既费人力又易出错。通用大模型能写出"像"的文字，却无法判断对错。

**方案.** Spec2Test 把条款编译成结构化测试意图：按版式坐标解析规范，产出统一中间表示（测试目的、步骤序列、信令 IE），再由确定性校验器用 TS 38.331 符号表和规则，检查消息与字段是否存在、测试目的是否被步骤覆盖。

**效果.** 评测遮住官方答案，只给测试目的与条款，生成后逐例比对。首期覆盖 TS 38.523-1 §6.7 的 8 个 NTN 用例，官方答案侧含 59 个步骤、25 张信令表、42 个叶子字段。脚本开源，失败逐条公示，分数见正文逐例矩阵[待填]。

**应用.** 面向测试仪表与终端厂商的协议测试团队、运营商测试中心：先做缩短用例编写周期的提效工具，再做规范变更分析与订阅服务。6G 尚未标准化，本方法在 NR Rel-19 上验证，格式同构，接入新代际主要是加语料。
