# 初赛提交规范与评分（2026-10-29 核实）

## 提交物（缺一即视为放弃）
1. 作品名称 ≤20 字
2. 作品简介 300–500 字（问题-方案-效果-应用）
3. 作品方案 PDF（按官方模板，**≤10M**；提交规范写 ≤15M，按 10M 做）
4. 演示视频 MP4，3–5 分钟，≤300MB
5. 答辩 PPT（转 PDF）
6. 佐证材料（合并一个 PDF：专利/软著/论文首页/合作意向/用户反馈/试点证明）
7. 其他材料：代码包等上传百度网盘，命名 `参赛团队编号-赛题名称-作品名称-材料名称`，永久有效+自动提取码

## 方案模板结构
作品简介 → 一、产品概述（（一）产品名称、（二）项目定位）→ 二、…（自定）→ 三、附录
排版：宋体；一级标题三号粗、二级四号粗、正文小四；A4 纵向；上下 2.5cm、左右 3cm；单倍行距

## 评分权重（创新产品，共 100）
35 / 15 / 15 / 15 / 10 / 10（六项标签待补，需人工阅读 附件2 第 2 页表格）

## 我方风险
- 佐证材料预计接近空白：无专利、无软著、无论文、无企业合作。
- 应对：以「可复现性证据包」替代——开源仓库 + 一键复现脚本 + 基准数据集 + 逐例评测报告 + 校验器缺陷注入记录，并在方案中明说"本作品的真实性由可复现性担保"。
